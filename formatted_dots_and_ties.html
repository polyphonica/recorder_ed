Dots and Ties

Dots and ties are rhythmic notation symbols that extend the duration of notes or rests beyond their basic values.

Dots

Definition: Dotted Notes

A dot placed after a note or rest extends its duration by half of its original value.

Mathematically speaking, dots add half the written value of the note to make it longer. For example, a minim/half note has the value of two crotchet/quarter note beats. If a dot is placed after a minim, half the value of the minim (one crotchet/quarter note beat) is added to the minim/half note to make a note that lasts 3 crotchet/quarter note beats.

Ties

Definition: Ties

A tie is a curved line connecting two notes of the same pitch. The notes are played as one continuous sound with a combined duration.

Characteristics of ties:

  • Used to extend notes across bar lines

  • Allows for durations that can't be written with a single note

  • The second note is not re-attacked; you hold through both notes

Example: A crotchet/quarter note tied to a minim/half note = 3 beats of continuous sound

Key Difference: Dots vs. Ties

  • Dot: Extends a single note by a fixed proportion (half its value)

  • Tie: Connects two separate notes of the same pitch into one sustained sound, allowing any custom duration

Summary: Key Terms

Dot

A symbol placed after a note or rest that extends its duration by half of its original value

Dotted Minim

A minim/half note (2 beats) with a dot, extending it to 3 beats

Dotted Crotchet

A crotchet/quarter note (1 beat) with a dot, extending it to 1½ beats (equals 3 quavers)

Tie

A curved line connecting two notes of the same pitch, combining them into one sustained sound

Bar Line

A vertical line dividing music into measures; ties are commonly used to extend notes across bar lines

  • A tie connects two notes of the same pitch into one continuous sound

  • Ties are used to extend notes across bar lines or create custom durations

  • When a tie is used, the second note is not re-attacked—you hold through both notes

  • The key difference: dots extend by a fixed proportion (½), while ties allow any custom duration

  • Avoid using ties within a bar when a single note or dotted note can be used instead
